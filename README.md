# Eternal Odyssey

**Eternal Odyssey** - A cutting-edge action RPG built with Unity 3D, pushing the boundaries of immersive gameplay and high-fidelity graphics. Dive into a relentless adventure, unravel mysteries, and forge your legend in an ever-expanding universe.

## 🌟 Key Features

- **Stunning 3D Graphics**: Powered by Unity's latest rendering pipeline for lifelike visuals.
- **Engaging Storyline**: A rich narrative filled with twists, challenges, and epic quests.
- **Diverse Gameplay**: Multiple modes including PvE, PvP, and co-op missions.
- **Customizable Characters**: Level up and personalize your hero with unique skills and gear.
